# POST /v1/agents

Create a new agent in the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`agents:write`

## Request body

At minimum, send `name` and either `instructions` or `system_prompt`.

```json
{
  "name": "Support Voice Agent",
  "instructions": "Answer product questions and route billing issues to support.",
  "status": "draft",
  "type": "inbound"
}
```

Common fields:

- `name`
- `description`
- `status`
- `engine`
- `type`
- `instructions`
- `system_prompt`
- `voice`
- `language`
- `tool_ids`
- `knowledge_source_ids`
- `metadata`

## cURL

```bash
curl https://api.elyntix.ai/v1/agents \
  -X POST \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Voice Agent",
    "instructions": "Answer product questions and route billing issues to support.",
    "status": "draft",
    "type": "inbound"
  }'
```
