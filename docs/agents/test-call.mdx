# POST /v1/agents/:id/test-call

Start a browser test call for an agent in the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scopes

`agents:write` and `calls:write`

## Path parameters

- `id` - agent ID

## Response

```json
{
  "data": {
    "livekitUrl": "wss://example.livekit.cloud",
    "roomName": "elyntix_ws_123_agent_123_test",
    "token": "eyJhbGciOi...",
    "callSessionId": "call_123"
  }
}
```

## Errors

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Agent not found.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

```json
{
  "error": {
    "code": "CONFLICT",
    "message": "Workspace call concurrency limit reached",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash
curl https://api.elyntix.ai/v1/agents/agent_123/test-call \
  -X POST \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/agents/agent_123/test-call", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
  },
});

const payload = await response.json();
console.log(payload.data);
```
