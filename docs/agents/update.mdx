# PATCH /v1/agents/:id

Update an agent in the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`agents:write`

## Path parameters

- `id` - agent ID

## Request body

Send the fields you want to update. At least one of `instructions` or `system_prompt` must be present.

```json
{
  "name": "Support Voice Agent",
  "status": "active",
  "system_prompt": "Answer product questions and route billing issues to support.",
  "language": "en-US"
}
```

## cURL

```bash
curl https://api.elyntix.ai/v1/agents/agent_123 \
  -X PATCH \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Voice Agent",
    "status": "active",
    "system_prompt": "Answer product questions and route billing issues to support.",
    "language": "en-US"
```
