# Elyntix AI API

Elyntix AI is a developer-first AI voice platform with a public `/v1` API for agents and call logs.

Use the API to:

- Create and manage agents
- Start browser test calls
- Read call sessions and call logs
- Keep all access scoped to a workspace through API keys

The API is designed for server-side integrations only. Never expose secret keys in a browser or frontend bundle.
