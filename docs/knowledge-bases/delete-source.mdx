# DELETE /v1/knowledge-bases/:id/sources/:sourceId

Delete a single source from a knowledge base.

## Authentication

Bearer API key required.

## Required scope

`knowledge:write`

## Path parameters

- `id` - Knowledge base ID
- `sourceId` - Knowledge source ID

## Response

```http
204 No Content
```

## Notes

- Deleting a source removes it from the knowledge base immediately.
- Agents will no longer be able to reference this source in their conversations.
- This action cannot be undone.
