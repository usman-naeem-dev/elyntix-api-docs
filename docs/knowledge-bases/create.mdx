# POST /v1/knowledge-bases

Create a new knowledge base in the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`knowledge:write`

## Request body

- `name` (required) - A unique name for the knowledge base
- `description` (optional) - A description of the knowledge base's purpose

```json
{
  "name": "Product FAQ",
  "description": "Frequently asked questions about our product"
}
```

## Response

```json
{
  "data": {
    "_id": "kb_123",
    "org_id": "org_123",
    "name": "Product FAQ",
    "description": "Frequently asked questions about our product",
    "source_count": 0,
    "chunk_count": 0,
    "last_ingested_at": null,
    "created_at": "2026-06-01T12:00:00.000Z",
    "updated_at": "2026-06-01T12:00:00.000Z"
  }
}
```

## Errors

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request payload.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or missing API key.",
    "requestId": "req_abc123def456",
    "details": null
  }

```

## cURL

```bash
curl https://api.elyntix.ai/v1/knowledge-bases \
  -X POST \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Product FAQ",
    "description": "Frequently asked questions about our product"
  }'
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/knowledge-bases", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Product FAQ",
    description: "Frequently asked questions about our product",
  }),
});

const payload = await response.json();
console.log(payload.data);
```
