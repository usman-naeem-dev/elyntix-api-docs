# DELETE /v1/knowledge-bases/:id

Delete a knowledge base and all associated sources.

## Authentication

Bearer API key required.

## Required scope

`knowledge:write`

## Path parameters

- `id` - Knowledge base ID

## Response

```http
204 No Content
```

## Notes

- Deleting a knowledge base removes all its sources.
- Any agents referencing this knowledge base will lose access to these sources.
- This action cannot be undone.

## Errors

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Knowledge base not found.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash
curl https://api.elyntix.ai/v1/knowledge-bases/kb_123 \
  -X DELETE \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/knowledge-bases/kb_123", {
  method: "DELETE",
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
  },
});

if (response.status !== 204) {
  const payload = await response.json();
  console.error(payload);
}
```
