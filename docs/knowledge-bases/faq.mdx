# POST /v1/knowledge-bases/:id/sources/faq

Add an FAQ (frequently asked questions) source to a knowledge base.

## Authentication

Bearer API key required.

## Required scope

`knowledge:write`

## Path parameters

- `id` - Knowledge base ID

## Request body

- `title` (required) - A name for this FAQ source
- `content` (required) - The FAQ content in Q&A format

FAQ content should follow this format for best results:

```
Q: Question here?
A: Answer here.

Q: Another question?
A: Another answer.
```

```json
{
  "title": "General Questions",
  "content": "Q: What is your product?\nA: Our product helps teams...\n\nQ: How much does it cost?\nA: Pricing starts at..."
}
```

## Response

The source is created with status `pending`. Processing begins immediately and typically completes within seconds. Once status reaches `ready`, the source is available to agents.

```json
{
  "data": {
    "_id": "src_456",
    "knowledge_base_id": "kb_123",
    "type": "faq",
    "status": "pending",
    "error_message": null,
    "title": "General Questions",
    "faq_content": "Q: What is your product?\nA: Our product helps teams...\n\nQ: How much does it cost?\nA: Pricing starts at...",
    "file": null,
    "chunk_count": 0,
    "char_count": 185,
    "created_at": "2026-06-01T12:00:00.000Z",
    "updated_at": "2026-06-01T12:00:00.000Z"
  }
}
```

## Polling for completion

After creation, poll the GET knowledge base endpoint to check when the source status becomes `ready`:

```ts
let source = await getSource(kb_id, src_id);
while (source.status !== "ready") {
  await sleep(1000);
  source = await getSource(kb_id, src_id);
}
```

## Errors

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Knowledge base not found.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request payload.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash

  -H "Content-Type: application/json" \
  -d '{
    "title": "General Questions",

```

## JavaScript / TypeScript

```ts
const response = await fetch(
  "https://api.elyntix.ai/v1/knowledge-bases/kb_123/sources/faq",
  {
    method: "POST",
    headers: {
      Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      title: "General Questions",
      content: "Q: What is your product?\nA: Our product helps teams...",
    }),
  }
);

const payload = await response.json();
console.log(payload.data);
```
