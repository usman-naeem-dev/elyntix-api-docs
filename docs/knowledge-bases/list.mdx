# GET /v1/knowledge-bases

List all knowledge bases that belong to the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`knowledge:read`

## Query parameters

- `limit` - optional, defaults to `20`, max `100`
- `cursor` - optional pagination cursor

## Response

```json
{
  "data": [
    {
      "_id": "kb_123",
      "org_id": "org_123",
      "name": "Product FAQ",
      "description": "Frequently asked questions about our product",
      "source_count": 5,
      "chunk_count": 42,
      "last_ingested_at": "2026-06-01T12:00:00.000Z",
      "created_at": "2026-06-01T10:00:00.000Z",
      "updated_at": "2026-06-01T12:00:00.000Z"
    }
  ],
  "pagination": {
    "limit": 20,
    "cursor": null
  }
}
```

## Errors

```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Invalid or missing API key.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash
curl "https://api.elyntix.ai/v1/knowledge-bases?limit=20" \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/knowledge-bases?limit=20", {
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
  },
});

const payload = await response.json();
console.log(payload.data);
```
