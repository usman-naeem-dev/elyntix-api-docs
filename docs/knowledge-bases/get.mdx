# GET /v1/knowledge-bases/:id

Retrieve a single knowledge base and all its sources.

## Authentication

Bearer API key required.

## Required scope

`knowledge:read`

## Path parameters

- `id` - Knowledge base ID

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Knowledge base not found.",
```

## cURL

```bash
curl https://api.elyntix.ai/v1/knowledge-bases/kb_123 \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/knowledge-bases/kb_123", {
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
  },
});

const payload = await response.json();
console.log(payload.data);
console.log(payload.data.sources);
```
