# PATCH /v1/knowledge-bases/:id

Update an existing knowledge base. Send only the fields you want to update.

## Authentication

Bearer API key required.

## Required scope

`knowledge:write`

## Path parameters

- `id` - Knowledge base ID

## Request body

- `name` (optional) - Update the knowledge base name
- `description` (optional) - Update the description

```json
{
  "name": "Updated Product FAQ",
  "description": "Updated description"
}
```

## Response

```json
{
  "data": {
    "_id": "kb_123",
    "org_id": "org_123",
    "name": "Updated Product FAQ",
    "description": "Updated description",
    "source_count": 2,
    "chunk_count": 15,
    "last_ingested_at": "2026-06-01T12:00:00.000Z",
    "created_at": "2026-06-01T10:00:00.000Z",
    "updated_at": "2026-06-01T12:30:00.000Z"
  }
}
```

## Errors

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Knowledge base not found.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request payload.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash
curl https://api.elyntix.ai/v1/knowledge-bases/kb_123 \
  -X PATCH \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Product FAQ"
  }'
```

## JavaScript / TypeScript

```ts
const response = await fetch("https://api.elyntix.ai/v1/knowledge-bases/kb_123", {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Updated Product FAQ",
  }),
});

const payload = await response.json();
console.log(payload.data);
```
