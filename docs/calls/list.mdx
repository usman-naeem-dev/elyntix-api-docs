# GET /v1/calls

List call sessions that belong to the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`calls:read`

## Query parameters

- `limit` - optional, defaults to `20`
- `cursor` - optional pagination cursor
- `status` - optional call status filter
- `agentId` - optional agent filter
- `type` - optional call type filter
- `from` - optional ISO date filter
- `to` - optional ISO date filter

## cURL

```bash
curl "https://api.elyntix.ai/v1/calls?limit=20&status=completed" \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

```ts
const url = new URL("https://api.elyntix.ai/v1/calls");
url.searchParams.set("limit", "20");
url.searchParams.set("status", "completed");

const response = await fetch(url, {
  headers: {
    Authorization: `Bearer ${process.env.ELYNTIX_API_KEY}`,
  },
});

const payload = await response.json();
console.log(payload.pagination);
```
