# POST /v1/calls/:id/end

End a browser test call session in the workspace attached to the API key.

## Authentication

Bearer API key required.

## Required scope

`calls:write`

## Path parameters

- `id` - call session ID

## Request body

No request body is required.

## Response

```json
{
  "data": {
    "id": "call_123",
    "agentId": "agent_123",
    "type": "browser_test",
    "status": "completed",
    "startedAt": "2026-06-01T12:00:00.000Z",
    "endedAt": "2026-06-01T12:03:20.000Z",
    "durationSeconds": 200,
    "estimatedCost": 0.67,
    "failureReason": null,
    "createdAt": "2026-06-01T12:00:00.000Z",
    "updatedAt": "2026-06-01T12:03:20.000Z"
  }
}
```

## Notes

- Only browser test call sessions are supported by this endpoint.
- The endpoint uses the existing call-ending logic in the platform backend.
- Outbound phone calls and SIP are intentionally out of scope.

## Errors

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Call session not found.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "Only browser test call sessions can be ended through this endpoint.",
    "requestId": "req_abc123def456",
    "details": null
  }
}
```

## cURL

```bash
curl https://api.elyntix.ai/v1/calls/call_123/end \
  -X POST \
  -H "Authorization: Bearer elyntix_sk_live_xxxxx"
```

## JavaScript / TypeScript

